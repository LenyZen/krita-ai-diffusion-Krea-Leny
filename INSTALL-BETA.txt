---------------------------------------------------------------------
 WHAT'S NEW IN THIS BETA (vs stock 1.52.1)
---------------------------------------------------------------------

  * Krea 2 image model support (T2I, inpaint, LoRAs, up to 4 refs)
  * Describe workspace — Florence-2 captions + Clio style library
    and Qwen-VL "Enhance Description" (image-grounded rewrite)
  * Augment workspace — up to 10 rectangular region edits
  * Animate (Wan) workspace — Wan 2.2 T2V / I2V / FLF2V, Extend, Stitch,
    progress bar, up to 3 Video LoRAs
  * SeedVR Enhance workspace — SeedVR2 diffusion upscale (separate
    from the existing ESRGAN Upscale tab)
  * "Krea 2 Turbo - ER SDE" sampler preset
  * Progress/result reliability fixes for slow model loads
  * Windows UTF-8 env for managed ComfyUI (avoids SeedVR emoji crash)

 REQUIREMENTS
---------------------------------------------------------------------

  * Krita 5.2 or newer
  * ComfyUI (plugin can install a managed server, or use your own)
  * NVIDIA GPU — 12 GB VRAM recommended for Krea 2 / Wan / SeedVR
  * git (to clone custom nodes)

---------------------------------------------------------------------
 STEP 1 — INSTALL THE KRITA PLUGIN
---------------------------------------------------------------------

BACK UP first if you already use AI Diffusion:

  rename  %APPDATA%\krita\pykrita\ai_diffusion
       -> %APPDATA%\krita\pykrita\ai_diffusion.bak

Option A — Import ZIP (easiest)

  1. Tools > Scripts > Import Python Plugin from File…
  2. Select this package zip
  3. Restart Krita when prompted
  4. Settings > Configure Krita > Python Plugin Manager
     → enable "AI Image Diffusion" if needed

Option B — Manual copy

  Copy into:  %APPDATA%\krita\pykrita\
              (C:\Users\<you>\AppData\Roaming\krita\pykrita\)

    ai_diffusion\           →  pykrita\ai_diffusion\
    ai_diffusion.desktop    →  pykrita\ai_diffusion.desktop

  Enable the plugin, then restart Krita.

Open the docker: Settings > Dockers > AI Image Diffusion.
First run: let it install a managed ComfyUI, OR point Connection
settings at your existing ComfyUI.

Everything below uses paths inside that ComfyUI folder.

---------------------------------------------------------------------
 STEP 2 — CUSTOM NODES
---------------------------------------------------------------------

In a terminal:

  cd <your-ComfyUI>\custom_nodes

Required for Krea 2 + Describe:

  git clone https://github.com/kijai/ComfyUI-Florence2.git
  git clone https://github.com/nova452/ComfyUI-Conditioning-Rebalance.git

Optional but recommended:

  git clone https://github.com/capitan01R/ComfyUI-Krea2T-Enhancer.git
  git clone https://github.com/1038lab/ComfyUI-QwenVL.git
      (Enhance Description + Clio styles in Describe)

For Animate (Wan):

  git clone https://github.com/stduhpf/ComfyUI-WanMoeKSampler.git
  git clone https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite.git

For SeedVR Enhance:

  git clone https://github.com/numz/ComfyUI-SeedVR2_VideoUpscaler.git
  Then install that pack's requirements into the ComfyUI Python env.
  On Windows, if the server dies at startup with UnicodeEncodeError,
  ensure PYTHONUTF8=1 (this beta sets it for managed servers) and/or
  pin transformers to 4.x:  pip install "transformers>=4.46,<5"

TOOLING-NODES PATCH (strongly recommended):

  The stock comfyui-tooling-nodes pack can freeze for minutes while
  scanning models on slow disks. Overwrite with the included patch:

    copy tooling-nodes-api.py
      →  custom_nodes\comfyui-tooling-nodes\api.py

  Re-apply after updating tooling-nodes.

Restart ComfyUI / Krita after installing nodes.

  my_models:
    diffusion_models: X:\models\diffusion_models\
    text_encoders: X:\models\text_encoders\
    vae: X:\models\vae\
    LLM: X:\models\LLM\
    loras: X:\models\loras\

---------------------------------------------------------------------
 STEP 4 — QUICK START BY WORKSPACE
---------------------------------------------------------------------

Generate (Krea 2)
  Style settings → new style → krea2_turbo_nvfp4
  Sampler preset: "Krea 2 Turbo - ER SDE" (8 steps, CFG 1.0)
  First run after server start is slow (encoder load); then faster.

Describe
  Detail level → Generate Description
  Optional: pick a Clio style, write a draft, Enhance Description
  "Use as prompt" sends text to Generate

Augment
  Select regions with Krita’s rectangular selection → Add region
  Per-region prompts + optional scene prompt → Generate

Animate (Wan)
  T2V = prompt only (needs wan2.2_t2v_*). I2V from current layer, or FLF2V first/last.
  Extend = continue from last frame; Stitch = FLF2V toward End frame
  Results land in the .kra Timeline (not an MP4). Export via
  File → Render Animation when you need a video file.
  Up to 3 Video LoRAs in the panel

SeedVR Enhance
  Separate from Upscale (ESRGAN). Pick preset, target size, Enhance.
  Needs SeedVR2 nodes; first run may download weights.

Known rough edges to watch:

  * First Krea / Wan / SeedVR run can look “stuck” while weights load
  * Stitch ≠ Extend (different behaviors)
  * SeedVR is image enhance only in this beta (not video batch)
  * Clio Enhance needs ComfyUI-QwenVL; captions still work with Florence-2 alone

---------------------------------------------------------------------
 TROUBLESHOOTING
---------------------------------------------------------------------

  * Plugin missing after install: confirm folder is named ai_diffusion
    and ai_diffusion.desktop is next to it; enable in Plugin Manager
  * "Could not find websockets": you installed source without vendored
    deps — use this zip, not a raw git checkout
  * Hang / lost results: apply tooling-nodes patch (step 2)
  * No caption model: Florence-2 folder under models\LLM + restart
  * QwenVL / SeedVR / Wan nodes missing: clone packs, restart server
  * SeedVR UnicodeEncodeError on Windows: UTF-8 env + avoid emoji
    prints; pin transformers < 5 if diffusers breaks

Have fun — and thank you for testing.
